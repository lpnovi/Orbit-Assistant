## C. About 150 words

> Orbit Assistant is a free, open-source Android assistant built for the moments when switching to a chatbot app breaks your flow.
>
> Set Orbit as Android's digital assistant and call it from the assistant gesture or, on many Samsung phones, the Side button. It appears over the app you are using. The current screen is offered, not sent: you tap to attach it or select an area. From there Orbit can answer, summarize, or hand real actions to Android, like timers, alarms, reminders, calendar events, media, and the flashlight.
>
> When you need more room, the same conversation continues in a full chat app with history, attachments, and PDF reading. Routines automate repeatable steps, Orbit Deck keeps your shortcuts one tap away, and Theme Studio lets you restyle the whole app.
>

> I use my phone's assistant button constantly, and I kept wishing it did more of what I wanted and less of what the manufacturer decided. Opening a chatbot, copying text in, and switching back felt clunky for the small things I actually needed help with.
>
> So I started building the assistant I wanted: one that shows up over whatever I'm doing, only looks at my screen when I tell it to, can actually set the timer or add the calendar event, and lets me change how everything looks and works.
>
> Orbit is an independent project. I've built it with a lot of help from AI coding tools, and I review, test, and use every Stable build on my own Galaxy S25 Ultra before it goes out. It's open source because an assistant that sits this close to your phone should be something you can inspect.

## H. FAQ

**Is Orbit free?**
Yes. Orbit Assistant is free to download and use, with no ads. Cloud AI uses your own ChatGPT account, so that account's own plan and limits apply.

**What is Orbit Pro?**
A planned optional paid layer of advanced customization extras, such as advanced Theme Studio styling and multiple saved Deck layouts. It is being tested in Beta builds only. Stable builds mention it briefly in Theme Studio and Orbit Deck, but never unlock it. Nothing that is free today will move behind it.

**Is there anything to buy right now?**
No. There is no checkout, no billing, and nothing to purchase.

**Does it require root?**
No. Orbit uses standard Android permissions and settings.

**Does it work only on Samsung?**
No. Orbit runs on Android 10 or newer. It is primarily tested on a Galaxy S25 Ultra, and Side-button mapping is a Samsung feature that is not available on every phone. On other devices you can use the system assistant gesture where available, the app, the Quick Settings tile, or widgets.

**Is Orbit Local required?**
No. Orbit Local is an optional separate download for offline chat on supported 64-bit phones. Most people start with ChatGPT sign-in, which offers Orbit's fullest feature set.

**Is it open source?**
Yes, under the Mozilla Public License 2.0. The full source for the app, Orbit Local, and the release workflows is on GitHub.

**Does it send screen content automatically?**
Not by default. Orbit offers the current screen, and it is attached only when you tap **Use screen** or **Select area**. You can change that globally or per app, and apps marked sensitive never attach screen content automatically. When you do send it, it goes to the AI provider you chose.

**How are updates installed?**
Orbit can check GitHub for new releases. When one is available, it asks before downloading, verifies the package, checksum, and signing certificate, and then hands the file to Android's normal installer for your confirmation. It never installs anything silently. You can also download new versions manually from GitHub Releases.

**Who makes Orbit?**
Orbit is an independent project published by lpnovi on GitHub, developed with substantial help from AI coding tools. It is not affiliated with or endorsed by OpenAI, Samsung, or Google.
